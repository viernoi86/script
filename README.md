---

# 🎮 Compatibilité

Le **Loadstring principal de Viernoi86hub est compatible avec les deux expériences** :

* 🔪 **Murder Mystery 2**
* 🔫 **Arsenal**

Le script s'adapte **automatiquement à l'expérience dans laquelle il est exécuté** et charge les fonctionnalités correspondantes.

Tu n'as donc pas besoin d'utiliser un Loadstring différent selon le jeu : **le même Loadstring peut être utilisé pour les deux expériences.**

## 🚀 Loadstring

```lua
loadstring(game:HttpGet("https://raw.githubusercontent.com/viernoi86/script/refs/heads/main/viernoi86hub.lua"))()
```

> Le script détecte l'expérience et s'adapte automatiquement en fonction du jeu.

# 🔪 MM2 Script

La partie **Murder Mystery 2** est actuellement la partie la plus développée de mes scripts.

## ✨ Fonctionnalités

* 🕊️ **Fly** — permet de voler.
* 👻 **Noclip** — permet de traverser les objets.
* 🔫 **Grab The Gun** — téléportation vers l'arme.
* 🪙 **Auto Coins** — récupération automatique des coins.
* 👁️ **ESP MM2** — affiche les joueurs avec l'ESP.
* 🔪 **TP Murder** — téléportation vers le Murder.
* 🔄 **Loop TP Murder** — téléportation en boucle vers le Murder.
* 🔫 **TP Sheriff** — téléportation vers le Sheriff.
* 🔄 **Loop TP Sheriff** — téléportation en boucle vers le Sheriff.
* 🏠 **TP Lobby** — téléportation vers le lobby.
* 🗺️ **TP Map** — détecte automatiquement la map actuelle et téléporte vers celle-ci.
* 🖥️ **UI Toggle** — permet d'afficher ou masquer l'interface.

## 🎮 Controls

| Touche          | Fonction                |
| --------------- | ----------------------- |
| **Right Shift** | Afficher / masquer l'UI |

# 🔫 Arsenal Script

Le projet **Arsenal** est également pris en charge par Viernoi86hub.

## ✨ Fonctionnalités

* ♾️ **Infinite Ammo** — munitions illimitées.
* ⚡ **Rapid Fire** — augmente considérablement la cadence de tir.
* 🎯 **Hitbox Expander** — agrandit les hitboxes des joueurs ennemis.
* 🌀 **Teleport to Enemy** — permet de se téléporter directement vers un joueur ennemi.
* ⌨️ **X Key Teleport** — utilise la touche X pour se téléporter vers un ennemi.
* 🖥️ **UI Toggle** — affiche ou masque l'interface avec Right Shift.

## 🎮 Controls

| Touche          | Fonction                            |
| --------------- | ----------------------------------- |
| **X**           | Téléportation vers un joueur ennemi |
